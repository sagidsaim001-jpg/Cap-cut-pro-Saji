# SAJI CUT

A native Android video editor inspired by modern mobile timeline editors. Built with Kotlin, Jetpack Compose, ExoPlayer and Media3 Transformer.

## Current editor foundation
- Import a video from device storage
- Video playback preview
- Timeline and playhead
- Trim start/end
- Split markers and clip segment selection
- Playback speed preview
- Rotate and aspect-ratio controls
- MP4 export through Media3 Transformer

## Build
Open in Android Studio or run `./gradlew assembleDebug`.
